# SuperChinese Web - Học Tiếng Trung Tương Tác

Ứng dụng học tiếng Trung tương tác mô phỏng SuperChinese (HSK 1 - HSK 6 & HSK 3.0).

- **Từ vựng**: Phát âm chuẩn, chữ Hán, Pinyin, nghĩa tiếng Việt, câu ví dụ thực tế.
- **Ngữ pháp**: Quy tắc ngữ pháp trọng điểm, giải thích chi tiết, mẫu câu áp dụng.
- **Hội thoại**: Video mô phỏng, phát toàn bộ đoạn thoại theo từng nhân vật, bài tập kiểm tra đọc hiểu.
- **Kiểm tra**: Bài kiểm tra nghe, phán đoán đúng sai, sắp xếp từ thành câu.
- **Tiến độ**: Tự động lưu tiến độ học tập trên thiết bị.
